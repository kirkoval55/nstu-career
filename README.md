# НГТУ Карьера

Файлы: index.html (сайт), netlify/functions/chat.js (функция с ключом Claude), netlify.toml (настройки).

Переменные окружения в Netlify:
- ANTHROPIC_API_KEY — ключ из console.anthropic.com
- ALLOWED_ORIGIN — адрес сайта без слеша, например https://name.netlify.app
- CLAUDE_MODEL — по желанию (по умолчанию claude-haiku-5-5)
